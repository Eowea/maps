Connexion à GitHub

Pour enregistrer tes modifications dans le dépôt, colle ici un token GitHub personnel ayant le droit d'écrire sur le dépôt visé ci-dessous. Il reste uniquement dans ton navigateur, il n'est jamais envoyé ailleurs qu'à l'API GitHub.

Rappel : créer un token
Ouvrir la création de token ↗ Photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
Pour toi (admin) Un seul token pour tous tes dépôts
  1. Token name : « Admin Eowea » · Expiration : longue (ex. 1 an).
  2. Repository access → Only select repositories → coche builds, buildtest et maps.
  3. Permissions → Add permissions → Contents → Read and write.
  4. Generate token, puis colle-le ci-dessous.
Pour un éditeur Tu le crées sur ton compte et tu le lui envoies
  1. Token name : son pseudo (ex. « Éditeur Pseudo »), pour le retrouver ensuite · Expiration : courte, tu renouvelleras.
  2. Repository access → Only select repositories → uniquement maps.
  3. Permissions → Add permissions → Contents → Read and write.
  4. Generate token, puis envoie-le-lui en privé avec ses identifiants du panneau (onglet Administrateurs).
  5. Pour lui couper l'accès : Fine-grained tokens → son token → Delete.

⚠ GitHub n'affiche le token qu'une seule fois : copie-le avant de quitter la page. Inutile d'inviter l'éditeur comme collaborateur sur GitHub.
